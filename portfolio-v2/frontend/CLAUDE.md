# portfolio-frontend

Next.js 16 (App Router, Cache Components, React Compiler), Tailwind v4, shadcn/ui (radix-nova), motion, RHF + Zod.

- Public content: `src/lib/content.ts` `getPortfolioContent()`, with `"use cache"` + `cacheLife("hours")` + `cacheTag`. It falls back to `src/data/fallback.json`, which is generated by `pnpm sync-fallback` in backend/. Don't hand-edit it.
- Admin edits call the `refreshPublicContent(token)` server action, which runs `updateTag`.
- Browser → API calls go through `src/lib/apiReq.ts` and the `src/lib/services/<domain>` modules. Never call axios directly.
- Zod schemas in `src/lib/validations/*` mirror `backend/validators/*`. Keep them in sync.
- `/admin` pages are thin server files (`export const instant = false`) that render client views from `src/components/admin/`.
- Read `node_modules/next/dist/docs/` before using unfamiliar Next APIs. This version differs from older training data.
